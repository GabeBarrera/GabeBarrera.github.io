You're signed in, but this account can't edit the site yet. To make it an admin, add it to the site_admins list in Firebase. This replaces a separate set-admin script; it's a one-time step.

—
—
  1. Open the Firebase console, then Firestore Database → Data.
  2. Click Start collection (or open site_admins if it exists). Collection ID: site_admins.
  3. Document ID: paste the UID above.
  4. Add a field role, type string, value owner. Save.
  5. Come back and press Check again.
